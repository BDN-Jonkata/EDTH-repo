# scenarios module

Scenario configs. Each file is one config; the seeder turns it into a scenario and its ground truth. See [seeder config](../docs/seeder-config.md).

Status: seven presets, generated by [seeder/scenario.py](../seeder/scenario.py).

| Preset | Hostiles | Degradations | Default seed |
|--------|----------|--------------|--------------|
| `easy` | 1 | none | 1 (tuning set) |
| `medium` | 3, one close crossing | 15 % loss, latency, small clock and pose error | 2 (tuning set) |
| `hard` | 5, hovering and sharp turns | fog, 40 % bursty loss, clock drift, pose error, node dropout | 3 (tuning set) |
| `challenge` | 2, crossing at close range | none (set them in the viewer) | 4127 |
| `busy` | 4 threat scenarios plus 4 non-allied benign drones: transit, off-site survey orbit, ambiguous hover and protected-area loiter | none; clear weather to watch all five automatic flags | 3 (tuning set) |
| `dusk` | 4, mixed motion | a sunset across the run (sky, one simulated minute per second), a fog patch in the middle from 30 s to 100 s, 2 birds and a vehicle | 5 (tuning set) |
| `jammed` | 3, one close crossing | 10 % loss, latency, a 32 kbit/s cap per node, a strong jamming zone in the north-east (30 s to 100 s) and a weaker permanent one in the west, a vehicle | 6 (tuning set) |

`dusk` and `jammed` use the weather events, sky, jamming zones and bandwidth cap added to the seeder; their numbers are assumptions chosen to show the effects, not measurements. Adding them did not change the other presets.

To watch the automatic behavior with more traffic, open
`http://localhost:8000/?preset=busy` or choose **busy** in the viewer's Preset picker.
The five friendly patrol drones share investigation work as contacts appear.
At about 61 s in the default busy run all five flags appear together. The seeder
defines physical paths and scoring roles; the estimator only receives noisy
observations and known policy. A benign scoring role never supplies an ally beacon
or forces a peaceful flag.
Changing the seed generates a different set of paths with the same traffic settings.

Seed sets: tuning seeds are 1-99, final-test seeds are 1000-1099. Never tune on the test seeds.

Generate:

```
python seeder/generate.py scenarios/challenge.json                       # writes out/<id>/scenario.json and truth.json
python seeder/generate.py scenarios/hard.json --seed-set test --index 3  # seed 1003
python seeder/generate.py scenarios/hard.json --save-db                  # also store in PostgreSQL
```
